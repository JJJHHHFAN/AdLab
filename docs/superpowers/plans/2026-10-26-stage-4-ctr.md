# AdLab 第四阶段：CTR 预测实现计划

**目标：** 用可复现的合成曝光数据完成无数据泄漏的 CTR 预测、模型比较和概率评估。

**架构：** `data/ctr_synthetic.py` 只生成数据；`algorithms/ctr.py` 只划分、训练和评估；`charts/ctr.py` 绘图；`ui/ctr.py` 展示交互与解释；SQLite 只保存配置及指标，不保存大量逐行数据。沿用项目的导航、首页和记录页。

**技术栈：** Python 3.12、NumPy、Pandas、scikit-learn、Plotly、Streamlit、SQLite、pytest。

## 数据与评估约定

- 每行是一条合成曝光，字段为匿名用户 ID、广告 ID、广告类别、展示时间与小时、设备、广告位、预实验期历史曝光和历史点击、当前是否点击。
- 历史特征在模拟曝光期开始前生成，整个当前数据集内保持固定；当前点击标签不参与任何历史特征计算。匿名 ID、时间戳和目标标签不进入模型；小时、广告及历史计数可用。
- 划分比例固定为训练 60%、验证 20%、测试 20%。随机模式按标签分层；时间模式按展示时间先后划分。两种模式的三组行索引均互斥。
- `ColumnTransformer` 与模型封装在 `Pipeline` 中，只对训练集调用 `fit`。验证集比较 Logistic Regression 和 Random Forest，以验证集 Log Loss 选一个模型；仅对选中模型计算测试集指标和图表。
- 指标为 AUC-ROC、Log Loss、Precision、Recall、Brier Score。Precision/Recall 使用可调阈值，默认 0.10；没有预测正例时 Precision 显示 N/A。测试集绘制 ROC、预测概率分布和概率校准图。
- 结果是合成数据实验，不代表真实广告点击率或线上收益；若某划分缺少任一类别，明确提示增大样本量或更换种子。
