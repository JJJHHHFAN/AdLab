# CTR 预测实验：数据、模型与评估

## 问题与数据

每一行代表一条**合成广告曝光**，目标 `clicked` 为 0/1。字段包括匿名用户 ID、广告 ID、广告类别、展示时间与小时、设备、广告位、前期历史曝光数、前期历史点击数和当前点击。生成器用固定随机种子创建隐藏的用户与广告偏好、位置和设备影响；这些是教学设定，不是从真实投放中估出的参数。默认 5,000 条合成曝光的点击率随种子变化，页面展示每次实际生成的比例。

历史计数在本次曝光模拟之前一次性生成，同一匿名用户的历史快照在本数据集中保持不变。当前数据的任何点击标签都不会被写进历史特征。用户 ID 仅用于标识，时间戳只用于划分；这两列和目标标签不进入模型。模型使用广告 ID、广告类别、小时、设备、广告位和两个历史计数。广告 ID 可帮助学习素材差异，但也可能记住本次合成样本的特性。

## 划分与防止数据泄漏

训练、验证、测试按约 60%/20%/20% 分开。**时间模式**先按展示时间排序，让较早数据训练、较晚数据验证和测试；**随机模式**按点击标签分层，适合学习静态分布下的建模流程。若任一组只有点击或只有未点击，实验拒绝运行，因为 AUC 等指标无法可靠计算。

随机模式可能让同一匿名用户的多条曝光分布在不同组，因此衡量的是对相似用户后续曝光的泛化，不是对全新用户的冷启动表现。反复查看测试集后据此调参也会让测试集失去独立性；本页面的自动模型选择只使用验证集。

类别编码和数值标准化放在 scikit-learn `Pipeline` 中，只在训练集调用 `fit`。验证集用于比较 Logistic Regression 和 Random Forest，并以较低的验证集 Log Loss 选择模型。测试集只报告该选中模型的一次结果。改变测试标签不会改变模型选择。这遵循 [scikit-learn 的数据泄漏建议](https://scikit-learn.org/stable/common_pitfalls)。

## 模型与指标

Logistic Regression 是线性概率基准：

\[
\hat p_i=\sigma(\beta_0+\beta^\top x_i),\qquad \sigma(z)=\frac{1}{1+e^{-z}}.
\]

Random Forest 汇集多棵决策树，可表达部分非线性与交互。两个模型都输出 `predict_proba` 的点击概率。此处并未做大规模超参数搜索或额外概率校准。

| 指标 | 解释 | 方向 |
|---|---|---|
| AUC-ROC | 点击样本通常能否排在未点击样本前面 | 越高越好；0.5 约为随机排序 |
| Log Loss | 对真实结果分配概率的对数损失；自信但错误的预测受更大惩罚 | 越低越好 |
| Precision | 在阈值以上、预测为点击的样本中有多少真的点击 | 越高越好，但须同时看 Recall |
| Recall | 真实点击中有多少被阈值捕获 | 越高越好，但须同时看 Precision |
| Brier Score | 预测概率与 0/1 结果的均方差 | 越低越好 |

设真实标签为 \(y_i\)，预测点击概率为 \(p_i\)：

\[
\mathrm{LogLoss}=-\frac1n\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)],\qquad
\mathrm{Brier}=\frac1n\sum_i(p_i-y_i)^2.
\]

Precision 与 Recall 使用页面可调的固定阈值，默认 0.10；AUC、Log Loss、Brier Score 使用原始概率。低 CTR 数据下，0.5 阈值可能几乎不预测任何点击。阈值改变不会重训模型，也不会改变概率指标。

**手算示例：** 四次曝光的预测概率为 0.1、0.7、0.2、0.6，真实点击为 0、1、0、1。Brier Score 为 \((0.1^2+0.3^2+0.2^2+0.4^2)/4=0.075\)。当阈值为 0.5 时，第 2 与第 4 次被预测为点击，Precision 和 Recall 均为 1；这个四行示例不能说明模型在真实数据上的表现。

ROC 曲线显示不同阈值下的排序取舍；概率分布显示点击和未点击样本预测值的重叠；校准图把预测概率分组，与各组实际点击比例比较。校准图的点会受样本量和分箱方式影响，Brier Score 也不能单独当成“校准程度”。参见 [scikit-learn 指标说明](https://scikit-learn.org/stable/modules/model_evaluation.html)与[校准曲线文档](https://scikit-learn.org/stable/modules/generated/sklearn.calibration.calibration_curve.html)。

## 现实业务与局限

实际 CTR 预测通常还要处理特征可用时间、用户和广告冷启动、采样偏差、延迟点击、分布漂移、隐私要求及线上延迟。离线指标不等于投放增量效果；预算分配或上线决策需要另外评估经济目标与线上实验。本实验的数据和结果均为合成、可复现的教学模拟。SQLite 只保存种子、样本量、划分、阈值和聚合指标；逐行数据与模型不写入记录。
